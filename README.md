## 🎯 Projects Breakdown

### 🔹 [01. Enterprise Company Infrastructure](./01-company-infrastructure)
- **Category:** DevOps & Infrastructure Engineering
- **Tech Stack:** Docker, Terraform, Nginx, Bash, GitHub Actions, Prometheus/Grafana
- **Overview:** Production-ready automated enterprise cloud & local infrastructure setup featuring IaC (Terraform), container orchestration (Docker), reverse proxying, monitoring, and CI/CD pipelines.

### 🔹 [02. Sentinel Habit Tracker & Analytics Engine](./02-sentinel-habit-tracker)
- **Category:** Full-Stack Web Application
- **Tech Stack:** Python / FastAPI, React / TypeScript, PostgreSQL, TailwindCSS
- **Overview:** High-performance daily habit tracker and productivity dashboard featuring real-time streak tracking, analytics visualizations, interactive UI, and secure API backend.

### 🔹 [03. AI Career Path & Skill Navigation System](./03-ai-career-path-system)
- **Category:** AI / ML & Full-Stack Systems
- **Tech Stack:** Python, OpenAI / LangChain, FastAPI, React, D3.js / Cytoscape
- **Overview:** AI-driven personalized career guidance engine that analyzes user skills, resume data, and industry trends to generate interactive career roadmaps and skill gap recommendations.

### 🔹 [04. Garage & Automotive Repair Management System](./04-garage-database-system)
- **Category:** Database Architecture & Enterprise Software
- **Tech Stack:** PostgreSQL / MySQL, Python, REST API, HTML5 / Modern CSS
- **Overview:** Database-centric Automotive Repair and Workshop Management System with complex relational modeling, vehicle service history, inventory control, and SQL analytical views.

### 🔹 [05. Staging & Multi-Environment Deployment System](./05-system-environment-staging)
- **Category:** Cloud Platform & DevOps
- **Tech Stack:** Kubernetes / Helm, Docker Compose, Bash / Python Automation, Nginx
- **Overview:** Automated multi-environment staging setup simulating production, staging, and preview environments with automated deployment scripts, configuration isolation, and health checks.

### 🔹 [06. Face Recognition Smart Attendance System](./06-face-recognition-attendance)
- **Category:** Computer Vision & Artificial Intelligence
- **Tech Stack:** Python, OpenCV, face_recognition, SQLite / PostgreSQL, Flask / FastAPI
- **Overview:** Biometric computer-vision attendance platform using live video stream face identification, anti-spoofing checks, automated log registration, and admin management portal.

### 🔹 [07. Intelligent Cafe Management & POS System](./07-cafe-management-system)
- **Category:** Full-Stack Point of Sale (POS)
- **Tech Stack:** Node.js / Express or Python, React / Vite, SQLite / PostgreSQL, WebSockets
- **Overview:** Comprehensive POS and kitchen operations manager for cafes/restaurants featuring live table grid, order management, kitchen display system (KDS), real-time WebSockets update, and billing.

### 🔹 [08. Intelligent Context-Aware Python Chatbot](./08-intelligent-python-chatbot)
- **Category:** Conversational AI & NLP
- **Tech Stack:** Python, LangChain / LlamaIndex, OpenAI API, FastAPI, Web UI
- **Overview:** Enterprise-grade conversational AI assistant featuring Retrieval-Augmented Generation (RAG), intent classification, session memory retention, tool calling, and clean web interface.

### 🔹 [09. Jarvis Voice-Activated Desktop Assistant](./09-jarvis-voice-assistant)
- **Category:** Voice AI & System Automation
- **Tech Stack:** Python, SpeechRecognition, pyttsx3 / Whisper / ElevenLabs, OS API
- **Overview:** Hands-free voice assistant supporting speech recognition, voice synthesis, smart desktop automation, web searching, system commands, and custom voice skill plugins.

### 🔹 [10. FreshMart E-Commerce & Grocery Delivery Platform](./10-freshmart-grocery-store)
- **Category:** Full-Stack E-Commerce
- **Tech Stack:** Python / FastAPI or Node.js, React / Modern Web, PostgreSQL, Stripe
- **Overview:** Modern online grocery store platform featuring product catalog, search & filtering, dynamic shopping cart, checkout integration, order status tracking, and admin inventory panel.

## 🛠️ Global Engineering Standards Applied Across Projects

1. **Modular & Clean Architecture**: Strict separation of concerns (Layered Backend, Reactive Frontend, Declarative IaC).
2. **Comprehensive Documentation**: Detailed `README.md` in every project folder specifying setup, dependencies, and API specifications.
3. **Containerization & Environment Isolation**: Dockerized environments and virtualized dependencies for seamless execution.
4. **Security & Performance**: Strict environment variable configurations, CORS security, input validation, and optimized SQL/REST queries.
