## 🚀 Quick Start & Local Execution

1. **Clone the master suite:**
```bash
git clone [https://github.com/SudeeraHemantha/Portfolio_Projects.git](https://github.com/SudeeraHemantha/Portfolio_Projects.git)
cd Portfolio_Projects

```


2. **Run the portfolio website locally:**
```bash
# Using Python built-in HTTP server
python3 -m http.server 3000

```


Open `http://localhost:3000` in your browser.
3. **Navigate to individual project directories** for containerized run instructions (e.g., `cd 01-company-infrastructure && docker-compose up -d`).
